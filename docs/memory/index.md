# Memory index

Small linked notes, one lesson or fact each, in Obsidian `[[note-name]]` style (the link is the file name without `.md`). Read this index, then open only the notes whose hook matches your task. Follow a note's links when they bear on the task too.

## Writing a note

- One lesson or fact per note, a few lines. File name in kebab-case; the first line is a `#` title.
- Start from what happened, then **Why** and **How to apply**.
- Link related notes with `[[note-name]]`; a link to a note not written yet is fine and marks a gap.
- Update the note that already covers the subject before adding a new one, and delete notes that turn out wrong.
- Add one line here per note: link, then the hook that tells an agent when to open it.
- **This repo is public.** A note that names clients, employer products, people or private paths goes in `private/` (gitignored, local only); everything else stays generic.
