# Style for documents other people read

Owner's choices from the partnership document (see [[partnership-doc]]):

- **Humble, not brag.** No hero with stats, no self-praise sections. Lead with how he works and what he has done.
- **Static.** No animation in anything that becomes a PDF.
- **A record of past work is not a catalogue.** "Project types I've done" lists experience; only "what we can sell" is an offer. No intro line saying the experience is for sale.
- **Label above value.** In cards, put the small label ("para quem", "e-mail") on its own line with the text below it, never in a two-column label/value grid.
- **No empty space.** Size boxes and type to fill each page or slide; leftover half-empty areas read as unfinished.
- **No repetition.** One idea appears once: an idea that runs on several platforms is one item, not one per platform.
- **Local files only.** Write HTML/PDF to `reference/`, never publish online artifacts.
- **No PDF until the owner approves the HTML.** Then follow [[html-to-pdf]].
- Contents must also pass [[employer-confidentiality]].
